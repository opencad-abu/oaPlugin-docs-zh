# oaPlugin 中文文档

oaPlugin 是 [AIVI](https://github.com/opencad-abu/aivi) 项目的 OpenAccess 插件子系统。

## 在线访问

https://opencad-abu.github.io/oaPlugin-docs-zh/

## 文档结构

| 文件 | 说明 |
|------|------|
| `index.html` | 文档主页（各模块总览） |
| `aivivc.html` | aivivc 版本管控插件 |
| `aividmfilesys.html` | DM 文件系统插件 |
| `aividmfilesysbase.html` | DM 文件系统基础库 |
| `aividmturbo.html` | DMTurbo 数据管理插件 |
| `aividmturbobase.html` | DMTurbo 基础库 |
| `aividmturbo_server.html` | DMTurbo 服务端 |
| `aivipcell.html` | 参数化单元插件 |
| `aivitext.html` | 文本渲染插件 |
| `aivilock.html` | 锁管理插件 |
| `aivilibdef.html` | 库定义插件 |
| `api.html` | API 参考 |
| `integration.html` | Virtuoso 集成指南 |
