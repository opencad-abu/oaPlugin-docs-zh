oaPlugin / aividmfilesysbase

aividmfilesysbase

这是 DM 文件系统的支撑库，不是独立的 OA 插件页面。它提供异常、消息和客户端-服务端 socket 封装，供 aividmfilesys 复用。

产物：liboaAiviDMFileSysBase.so
定位：DM FileSys 的消息层、错误层和 oaCSMsg 传输层。
关系：被 aividmfilesys 调用，不单独提供 LM 菜单或用户界面。

导出接口

符号用途
ExceptionDMFileSys 基础异常对象，保存消息 ID 与消息表范围。
Error带格式化参数的错误对象，通常用于失败路径回报。
InfoMsg信息消息对象，和错误分表管理。
oaCSMsg客户端-服务端 socket 包装，给锁服务或控制服务通信用。
getDMFileSysMsg()按错误 ID 取出错误文本。
getDMFileSysInfoMsg()按信息 ID 取出提示文本。

调用方式

  1. 主模块先创建 oaDMFileSysComp 或锁管理对象，再按需要构造异常或提示消息。
  2. 需要进程间通信时，使用 oaCSMsg 打开 Unix domain socket 并发送请求。
  3. 错误和提示文本通过消息 ID 统一管理，便于前后端保持一致。
oaDMFileSys::Error err(oaDMFileSys::oacLibNotFoundErr, "myLib");
oaDMFileSys::oaCSMsg msg;
msg.send(1001, "%s", "lock request");

接口边界

这个库的职责是把 DMFileSys 的通用基础能力拆出来，减少主插件中的重复代码。它本身不承担库、cell、view 的对象映射，也不处理界面逻辑。
