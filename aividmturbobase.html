oaPlugin / aividmturbobase

aividmturbobase

这是 DMTurbo 的支撑库，提供客户端-服务端协议、流序列化、内存数据库对象和服务器管理类。它是 aividmturbo 与 aividmturbo_server 的公共底座。

产物：liboaAiviDMTurboBase.so
定位：协议层、对象模型层、服务器管理层。
边界：不直接面向用户界面，主要给客户端插件和服务端进程复用。

导出入口

符号用途
oaDMTurboInit()初始化底座库的注册表和运行时对象。
DMTurboExit()退出清理入口。

核心接口

接口/类用途
IChannelTCP 连接抽象，负责连接服务器和收发字节流。
CSMsg客户端-服务端消息包装，封装 request/response。
Stream二进制序列化流。
StringTbl字符串驻留表，给协议对象节省重复字符串开销。
DMObject / DMLib / DMCell / DMView / DMCellView / DMFile服务端内存数据库对象树。
LibServer / LibServerMgr库服务器和服务器管理器。

协议消息

消息说明
kMsgCreateLib / kMsgOpenLib / kMsgCloseLib库生命周期操作。
kMsgCreateCell / kMsgFindCell / kMsgDestroyCellCell 相关操作。
kMsgCreateView / kMsgDestroyViewView 相关操作。
kMsgCreateFile / kMsgFindFile / kMsgDestroyFile文件对象相关操作。
kMsgLock / kMsgUnlock / kMsgHasLockedFiles锁状态相关操作。
kMsgSave / kMsgLoad / kMsgPing / kMsgShutdown持久化与控制信号。

调用方式

  1. 客户端插件通过 IChannel 连接服务端。
  2. 使用 CSMsg 组装请求并发送，服务端按协议更新内存对象树。
  3. 服务端把状态写回 server.xml 或对应库目录，供后续连接复用。

简单说，这一层是“DMTurbo 的公共语言”。真正的 OA 插件和服务端都建立在这个语言之上。
