oaPlugin / aivilibdef

aivilibdef

这是 lib.defs / cds.lib 的读取和写回工具库，面向 OA 的 ILibDef 入口。它更像一个基础设施模块，而不是面向最终用户的 UI 插件。

入口：oaAiviLibDefInit() 与 getClassObject()
注册名：oaAiviLibDef、oaAiviLibDefSystem、oaLibDef、oaLibDefSystem
接口：ILibDef

主类

组件说明
AiviLibDef实现 ILibDef 的主类。
FactoryOA 工厂对象，供插件管理器加载。

常用方法

方法作用
init()接收 ILibDefAccess。
open()打开默认库定义文件。
open(path, openReferences)按指定路径打开并递归处理引用。
save() / saveAs()把修改写回到 lib.defs 或 cds.lib。
getDefaultPath() / getDefaultFileName()计算默认入口文件。
hasPath() / hasWritePath()报告路径能力。

调用流

  1. OA 调用 open() 进入默认库定义文件。
  2. 解析 ai.lib、lib.defs 或 cds.lib 中的条目。
  3. 按需要递归打开引用库，并把结果写回。
  4. 修改后通过 save() 或 saveAs() 输出新文件。
AIVI_LIBDEF_DEBUG=1

如果要追踪库定义解析过程，可以打开 AIVI_LIBDEF_DEBUG。这个库主要用于把 OA 的库定义入口统一起来。
