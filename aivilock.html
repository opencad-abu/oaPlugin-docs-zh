oaPlugin / aivilock

aivilock

这是 pthread 版本的锁后端，目标是兼容 liboaLockCDS.so 的 ABI 形态。它提供 mutex、spin mutex、rwlock 和录制锁工厂。

定位：底层锁实现，不是 OA 业务插件。
入口：getClassObject() 返回 LockFactoryMgr::get()。
用途：给 OA/DM 组件提供锁工厂和录制接口。

核心类型

类型说明
Mutex / SpinMutex / RWLock基础锁实现。
RecordingMutex / RecordingSpinMutex / RecordingRWLock带记录能力的锁实现。
ThreadRecording线程级锁记录容器。
LockFactoryMgr锁工厂总管，负责初始化、注册和查询。

常用接口

方法作用
init()选择工厂类型并完成初始化。
enableLocking() / enableLockingForResType()控制锁功能开关。
startRecording() / stopRecording()开启或关闭锁记录。
registerThread() / unregisterThread()登记线程 ID。
getLockFactory()按 GUID 查找具体锁工厂。
isLockingEnabled()查询当前锁是否启用。

调用方式

  1. OA 或 DM 代码先拿到 LockFactoryMgr::get()。
  2. 按当前运行模式调用 init()，选择 CDS 或 recording 工厂。
  3. 后续对象锁通过工厂创建的 mutex / rwlock 实例完成。

这层主要解决“锁实现应该长什么样”这个 ABI 问题，属于非常底层的支撑库。
