oaPlugin / aivipcell

aivipcell

这是 Python3 PCell 桥，把 OA 的 PCell 定义映射到 Python 模块和函数。它的目标是让参数化单元的生成逻辑留在 Python，OA 侧只负责读写和调度。

构建目标：oaAiviPcell
接口：IPcell，外加 oaPcellDef 的持久化支持。
环境：通过 ACELL_PYTHONPATH 扩展 Python 导入路径。

导出入口

符号用途
getClassObject()OA 加载器标准入口，返回 PCell 工厂。

主类

组件说明
AiviPcell插件主类，执行 Python evaluator 并把结果写回 OA。
PcellDef持久化包装，保存模块名、函数名和 schema 元数据。

元数据键

键用途
AcellModule / AcellFunc首选 Python evaluator 的模块和函数名。
PyModule / PyFunc兼容别名，便于旧数据迁移。
AcellVersion / AcellSchema持久化版本和 schema 号。

常用方法

方法作用
getPcellDef()返回绑定的 PCell 定义。
onBind() / onUnbind()绑定和解绑时处理元数据。
onEval()导入 Python 模块、传递参数并执行 evaluator。
onDiskLoad() / onDiskSave()序列化和恢复 PCell 元数据。
calcDiskSize()计算持久化大小。

调用流

  1. OA 读取 PCell 定义并恢复模块名、函数名和 schema。
  2. AiviPcell 调用 Python 解释器，并在需要时补充 ACELL_PYTHONPATH。
  3. 把 OA 参数转换成 Python 字典，再调用 evaluator。
  4. 把返回的几何、引脚、网络和属性写回 OA 设计对象。
export ACELL_PYTHONPATH=./python
