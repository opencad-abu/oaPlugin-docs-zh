oaPlugin / aivivc API

AIVIVC 接口 API 文档

本页覆盖 aivivc 的对外接口。aivivc 是 OpenAccess 版本控制插件和 Cadence GDM 桥接层，底层版本管理仍由 Git 或 SVN 工具完成。

接口速查

接口面调用者入口主要用途
OA VC 插件OA 插件管理器 / AIVIoaAiviVCInit()、getClassObject()注册 IVersionControl/IVCSystem。
GDM 命令适配器SKILL、原生封装库、命令行测试aivivc-gdm <cmd> ...统一执行状态、checkout、commit、cancel、update、history、protect。
原生 GDM 封装库Cadence GDM 加载器libgdmaivivc_sh.so、gdmaivivcWrapFuncs把 Cadence GDM 函数表调用转发到 aivivc-gdm。
Library Manager SKILLVirtuoso Library ManageraivivcCallbacks.il、aivivcLibMgr.il提供菜单、弹窗、选中对象到文件路径的解析。

GDM/SKILL 环境变量

后端选择和路径映射

AiviVCBackend=auto 时按 SVN marker、Git worktree、SVN info 的顺序探测；都失败时回退 Git。

OA 操作语义

OA 方法Git 行为SVN 行为
getStatus()git ls-files、git status --porcelain=v1 -bsvn info、svn status -u
getVersions()git log -n 50 --format=%h -- <path>svn log -q -l 50 <path>
update(version)有版本时 checkout 指定版本，否则 git pull --ff-onlysvn update [-r version] <path>
makeEditable(lock)写入 Git checkout marker，并让受控文件可写。写入 fallback marker，并在 lock=true 时执行 svn lock。
cancelEdit(recurse)git reset、git checkout，递归时 git clean -fd；成功后清 marker 并只读保护。svn revert，递归时加 -R；成功后清 marker 并只读保护。
commitEdits(comment)git add、git commit；无改动视为成功；成功后释放 marker。svn commit；成功后释放 marker。
setControlled()必要时 git init，然后 git add；成功后只读保护。svn add --parents；成功后只读保护。
unsetControlled(keepLocal)git rm -r；保留本地时加 --cached。svn delete；保留本地时加 --keep-local。

状态语义

  • Git ??、A、D、M/R/C、U/! 分别映射到 Added、Controlled/Added、Deleted、Modified、Conflict/Missing。
  • Git branch behind/diverged/gone 映射为 Remote；ahead 映射为 Modified。
  • SVN A/D/M/C/! 分别映射到 Added、Deleted、Modified、Conflict、Missing；含 * 表示 Remote。
  • checkout marker 属于当前用户且文件可写时为 Editable；属于其它用户时为 Locked。
  • git status clean 不等价于 GDM checked-in；aivivc 的编辑状态由 checkout marker 和文件写权限共同决定。

GDM 命令适配器

aivivc-gdm 解析 GDM 风格参数后调用 Git/SVN，并维护 AIVIVC checkout marker。

命令说明
status显示目标状态。
status-code给原生封装库使用的单行机器可读状态。
history显示目标历史。
coMake Editable，写 checkout marker 并打开写权限。
ci / submit提交改动；无改动也释放 marker。
cancel回退改动并释放 marker。
update更新版本并保护未 checkout 文件。
protect把目标受控文件设回只读；跳过当前用户已 checkout 的 marker 路径。
 
aivivc-gdm status -file "$TARGET"
aivivc-gdm status-code -cdslib "$WORKAREA/cds.lib" -lib myLib.myCell:schematic/sch.oa
aivivc-gdm co -file "$TARGET"
aivivc-gdm ci -message "Commit from Virtuoso" -file "$TARGET"

status-code 输出

display=CHECKED_IN co= perm=READ modified=0 deleted=0 update=0 managed=1 dir=0 label='Check in'
字段值说明
displayCHECKED_IN、CHECKED_OUT、OUT_OF_DATE、LOCKED、UNMANAGED给 GDM/Library Manager 显示偏好使用的状态名。
co空、CO、COECadence 低层 checkout slot 值。
permREAD、WRITE只有当前用户 checkout 且文件可写时返回 WRITE。
modified/deleted/update0/1表示修改、删除或远端更新需求。
managed/dir0/1表示是否受 Git/SVN 管理以及是否目录。
label文本给弹窗或命令行显示的状态。

原生 GDM 封装库

原生 GDM 封装库产物名为 libgdmaivivc_sh.so。Cadence 加载器按 DMTYPE aivivc 查找 gdmaivivcWrapFuncs。

槽位封装库函数行为
0dmServerGetWrapName返回 aivivc。
7dmServerOperation归一化 GDM 操作名并调用 aivivc-gdm。
13/14manageable/unmanaged 查询基于 status-code managed。
15checkout status空、CO 或 COE。
16delete status删除或缺失时返回 DEL。
17modified status修改或新增时返回 MOD。
18permission statusREAD 或 WRITE。
29update-needed status基于 Git behind/diverged/gone 或 SVN status -u。

Virtuoso SKILL/GDM 对接点

gdmSpec = gdmCreateSpec("myLib" "myCell" "schematic" "sch.oa" "CDBA")
gdmstatus(gdmSpec 6) ; 设计管理状态：gdmStateCI/gdmStateCO/gdmStateCOE
gdmstatus(gdmSpec 7) ; 工作区状态：gdmStateRead/gdmStateWrite
API用途
lmgrDefineInits注册 Library Manager 启动加载表达式。
lmgrCreateMenu / lmgrCreateMenuItem / lmgrAddMenuItems创建菜单和菜单项。
lmgrSensitizeMenuItems在 menu pre-map 时根据当前选择启用或禁用菜单项。
ddSetLibDmType对已写 DMTYPE aivivc 的 library 刷新 DD 内存状态。
ddUpdateLibList / ddsRefresh状态改变后刷新 Library Manager/DD 视图。
